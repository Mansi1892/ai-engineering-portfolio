Project-level READMEs are retained as historical documentation and may use the original author's voice; the main README and portfolio website use explicit ownership labels.

No standalone license file was present at the root of either source repository when this integration was prepared. Existing in-project notices, credits, and documentation have been retained. Publication or reuse outside the permission described by the repository owners should be reviewed separately.
